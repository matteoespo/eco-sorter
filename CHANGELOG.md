# Changelog

All notable changes to the Eco-Sorter project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [2.0.0] - 2025-06-01

### Added

- European recycling rules and region-specific sorting guidelines
- Improved frontend UI/UX with enhanced user experience

### Fixed

- YOLO weights download and loading issue
- Ollama container startup and connectivity fix

### Changed

- Refactored YOLO weight management for cleaner architecture and maintainability

## [1.0.0] - 2025-01-01

### Added

- Next.js frontend for waste classification interface
- FastAPI computer vision backend with YOLO object detection
- Ollama LLM integration for intelligent recycling guidance
- Docker Compose setup for full-stack local deployment
- Comprehensive `.gitignore` for Python, Node.js, and Docker artifacts
